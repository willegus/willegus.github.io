# willegus.github.io

Hemsida för mina gitarrcovers på TikTok.

## Publicera på GitHub Pages (gratis)

1. Logga in på github.com och klicka **New repository**.
2. Döp repot till exakt **`willegus.github.io`**, välj **Public** och klicka **Create repository**.
3. Klicka **uploading an existing file** och dra in `index.html`, `style.css`, `script.js`, `strings.js` och `README.md`. Klicka sedan **Commit changes**.
4. Gå till **Settings → Pages** och kontrollera att Source är **Deploy from a branch**, med branch **main** och mappen **/ (root)**.
5. Efter en minut eller två ligger sidan på **https://willegus.github.io**.

## Uppdatera sidan

Allt du behöver ändra ligger högst upp i `script.js`:

- **VIDEOS**: klistra in länken till ett TikTok-klipp på en ny rad (inom citattecken, med kommatecken efter).
- **GEAR**: byt ut platshållarna mot dina gitarrer, förstärkare och pedaler.
- **TEXTS**: alla texter på svenska (`sv`) och engelska (`en`).

E-postadressen står på två ställen i `index.html`. Sök efter `placeholder@gmail.com`.

Om du vill redigera direkt på GitHub öppnar du filen, klickar på pennan, ändrar och klickar **Commit changes**. Sidan uppdateras inom någon minut.
